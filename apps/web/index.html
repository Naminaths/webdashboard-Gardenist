Arsitektur End-to-End

Bagaimana sinyal analog dari tanah diubah menjadi telemetri real-time dan otomasi di genggaman Anda.

01

Sampling Fisik & Edge Autonomy

Mikrokontroler ESP32 membaca data dari 6 sensor setiap beberapa detik, memproses filter moving average, dan mengeksekusi logika irigasi secara mandiri meski Wi-Fi terputus.

02

Sinkronisasi Cloud Firebase

Data dikirim via WebSocket terenkripsi ke Firebase Realtime Database. Perubahan status saklar dan telemetri tersinkronisasi instan dengan latensi di bawah 15 milidetik.

03

Dashboard Analitik & Kontrol

Web dashboard menyajikan visualisasi data live, tren grafik Chart.js, perhitungan Eco-Score (0–1000 poin), serta ekspor riwayat aktivitas resmi dalam format PDF dan CSV.
