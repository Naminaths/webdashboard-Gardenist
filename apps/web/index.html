Alur Kerja Sistem

Dari Sensor Tanah Hingga Dashboard Realtime

Arsitektur end-to-end yang menyederhanakan pemantauan teknologi kebun modern tanpa kerumitan konfigurasi jaringan rumit.

01

Pembacaan Fisik Sensor

Mikrokontroler ESP32 membaca data analog & digital dari 6 sensor setiap beberapa detik dan memproses filter rata-rata bergerak (moving average) untuk akurasi tinggi.

02

Sinkronisasi Cloud Realtime

Data telemetry dikirim secara terenkripsi ke Firebase Realtime Database via protokol WebSocket ringan, memungkinkan update instan dengan efisiensi bandwidth maksimal.

03

Kontrol & Analitik Visual

Dashboard web menyajikan indikator live, grafik tren historis, notifikasi alarm visual, serta kontrol saklar manual yang dapat diakses dari smartphone maupun PC Anda.
